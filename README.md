# go-calendar-backend

Backend-сервис на Go для учёта пользовательских событий: создание, редактирование, удаление, получение событий на день, неделю и месяц. Система состоит из двух независимых микросервисов - сервиса аутентификации и сервиса событий, каждый со своей базой данных. Общая авторизация реализована через JWT-токен, а Redis используется для чёрного списка отозванных токенов и кэширования списков событий.

## Стек
- Go 1.25
- chi
- PostgreSQL
- Redis
- golang-migrate
- JWT
- bcrypt
- Docker Compose

## Архитектура
- **auth-service** (`:8081`) — регистрация, логин, logout, своя БД
- **events-service** (`:8080`) — CRUD событий с фильтром по дню/неделе/месяцу, своя БД
- Сервисы не общаются напрямую: JWT валидируется в events-service самостоятельно (подпись + чёрный список в Redis)
- Redis: чёрный список токенов (auth) + кэш списков событий с инвалидацией (events)

## Запуск

```bash
cd deployments
docker compose up --build
```
